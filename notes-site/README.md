# 数学思维学习札记

独立的静态阅读网站，无登录、数据库、AI 调用或旧平台入口。
仅部署本目录；原精准教学平台源码保留在仓库其他目录，不作为本网站的公开内容。

首页：`index.html`；样式：`styles.css`；公安备案图标：`assets/beian.png`。
ICP备案：京ICP备2026068374号-1。公安备案：京公网安备11010802050729号。
两个备案链接指向官方查询页面，公安图标在备案号左侧。

当前三篇基础数学文章为建站时整理的入门笔记，后续可直接编辑 HTML 添加或替换为个人资料。
不包含虚构的作者履历、研究成果或用户数据。

部署时将本目录发布到独立 Nginx 静态根目录，不要将整个代码仓库设为公开根目录。
