# SOLO 进阶支持规则

## 使用原则

- 进阶目标遵循 Plus One：只指向相邻层级；
- 目标必须说明学生下一步要形成什么思维结构，而不是只写分数或完成度；
- 策略优先服务当前精准教学主题的后续学习，并说明可迁移的方法；
- 每名学生给 2—4 条策略；
- 策略需包含具体动作和使用时机；
- 除非用户明确要求，不直接给出当前诊断任务的完整答案。

## P → U：进入任务并形成一个有效点

目标：从没有进入任务，转向自主识别并表达一个与任务直接相关的有效信息或判断。

可选策略：

- 用自己的话重述“任务要我解释、判断或完成什么”；
- 从材料中圈出一个最能回答问题的信息，并说明它与问题的直接联系；
- 回忆一个相关概念、事实或经验，先形成一个有依据的判断；
- 在接受提示前先独立写下一点，避免只确认他人的答案。

## U → M：扩展多个相关方面

目标：在一个有效点之外，补充多个彼此不同且与任务相关的方面。

可选策略：

- 从对象、条件、过程、证据、结果等不同角度补充信息；
- 使用列表或表格检查已经考虑和遗漏的方面；
- 比较不同案例、材料片段或变量，寻找第二、第三个相关点；
- 检查新增内容是否真正不同，避免同义重复。

## M → R：建立关键关系与整体结构

目标：把多个相关点按任务所需的关系组织起来，形成完整解释、论证或解决结构。

可选策略：

- 明确写出“因为—所以”“如果—那么”“证据—结论”“相同—不同”等关系句；
- 对信息进行比较、分类、排序或因果连接；
- 使用关系图、流程图、因果链、概念图或证据链组织已有信息；
- 完成后追问：这些点共同怎样支持我的结论？是否还有断开的信息？

## R → EA：抽象、迁移或检验结构

目标：在完整回答当前任务之后，将其提升为可概括、可迁移、可检验或有边界的高层结构。

可选策略：

- 从当前答案中提炼可用于其他情境的一般原则；
- 把同一结构应用到一个新情境，并说明哪些条件保持、哪些改变；
- 提出“如果条件改变会怎样”的假设并推演结果；
- 寻找正例、反例和边界条件，检验原解释的适用范围；
- 比较两种模型或解释，依据证据说明何时采用哪一种。

## EA → 更高质量 EA

目标：提升抽象结构的适用范围、解释力、证据质量和可修订性。

可选策略：

- 在更远的新领域检验迁移，而非只换一个表面相似案例；
- 比较多个模型的假设、解释力和局限；
- 整合多种来源的证据，并处理证据冲突；
- 根据反例或新证据修订模型、边界条件或原假设；
- 从现有结构生成一个新的可研究问题或概念框架。

## 教师端策略生成要求

每条策略需要把SOLO进阶方向转化为当前精准教学主题中的具体学习行动：

1. 指向诊断中已经识别的问题；
2. 使用当前主题中的学习对象、材料类型或任务类型；
3. 给出教师和学生能够观察的完成表现；
4. 最后说明该方法还可迁移到哪类相似任务。

不得为了贴近主题直接补全当前诊断任务的答案。策略的作用是规定学生如何加工信息、建立关系、形成整体或迁移结构。

## 写作模板

每条策略写成：

> 针对【已识别问题】，在【当前精准教学主题】的后续学习中，先【具体行动】，再【检查或表达方式】。完成表现为【可观察结果】；这一方法还可用于【相似任务】。

不要使用无法执行的表述，如“提高思维能力”“深入理解”“多动脑”。
