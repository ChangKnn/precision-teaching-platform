# SOLO 进阶与课堂教学干预规则

本文件整理自用户为本 Skill 明确提供的规则。它是内部规则资源，不作为运行时输入；不得用其他 SOLO 理论版本替换其核心逻辑。

## 一、基本进阶方向

| 当前与目标层级 | 进阶含义 | 课堂干预方向 |
|---|---|---|
| P（前结构）→ U（单点结构） | 认知定向 | 帮助学生进入学习任务，聚焦核心信息并形成至少一个有效认知点。 |
| U（单点结构）→ M（多点结构） | 信息扩展 | 引导学生从单一要素扩展到多个彼此不同且相关的要素。 |
| M（多点结构）→ R（关联结构） | 关系建构 | 引导学生建立要素之间的关键关系并形成整体理解。 |
| R（关联结构）→ EA（拓展抽象结构） | 迁移与抽象 | 引导学生进行概括、迁移、假设、评价和反思。 |
| EA（拓展抽象结构）→ 更高水平 EA | 深化抽象结构 | 支持远迁移、多模型比较、边界分析、假设生成和知识重构。 |

层级不是固定学生标签。所有含义都要结合当前精准教学内容、学生实际障碍和上游进阶目标进行具体化。

## 二、转化为课堂干预的要求

### 1. 面向课堂实施

把进阶方向转化为教师能够组织、学生能够完成并产生可观察产出的学习活动，不停留在抽象目标。

### 2. 优先处理代表性问题

先聚合具有相似进阶障碍和目标的学生需求，形成少量可覆盖多名学生的干预方向。不要为每名学生分别生成完整方案。

### 3. 匹配组织形式

- 全班共同指导：适合影响教学目标达成、且在多个层级反复出现的共同问题；
- 同质小组：适合共同障碍、相近进阶目标的集中补救或进阶；
- 异质小组：适合不同思维优势能够围绕同一任务互补建构；
- 个体学习或个别辅导：适合少数学生的独特障碍，或无法通过共同活动覆盖的需要。

### 4. 使用可操作的活动类型

可根据任务需要选择：

- 关键信息辨析；
- 多要素列举与补充；
- 比较与分类；
- 因果分析；
- 自我解释；
- 概念图或关系图；
- 变式任务；
- 反例分析；
- 新情境迁移。

活动必须结合 `precision_teaching_context` 具体化，不能机械地把某种活动固定绑定某一层级。

### 5. 控制实施成本

优先使用普通课堂已有材料、纸笔、小组讨论、板书或常规数字工具能够完成的活动。若建议需要额外资源，应说明资源和管理成本；没有必要时不引入复杂技术配置。

### 6. 保持教学决策粒度

输出活动方向、组织方式和预期认知变化即可。不展开完整课时流程、逐字教师话术、AI 话术或详细支架脚本。

## 三、诊断依据的使用顺序

生成干预时综合以下信息：

1. 上游 Skill 2 已确定的 SOLO 层级；
2. 学生思维结构特征；
3. 主要进阶障碍；
4. Plus One 进阶目标；
5. `precision_teaching_context` 中的主题、目标与内容；
6. 上游学习策略中可聚合为课堂活动的部分。

不能只根据层级代码生成固定建议，也不能用课堂活动反过来重判学生层级。
