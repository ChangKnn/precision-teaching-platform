# 小组教学建议规则

## 分组

1. 先按本次诊断的 SOLO 层级组织，同层人数较多时根据学生实际困难细分。不跨层级凑人数，不猜测未关联学生的困难。
2. 同层尽量形成便于组织的小组；人数少时保留真实人数，供教师灵活安排。每名参与诊断的学生恰好出现一次。
3. 分组是本次任务的临时安排，不形成固定能力标签。当前平台只采用同质方案，不要求额外生成异质分组。

## 命名与呈现

- 从学习任务提炼核心活动，使用2—6字短语加“组”，如“方法比较组”“证据检验组”；具体名称须符合本组实际任务。
- 不把学生的问题、SOLO层级名或任务的整句要求当作组名。
- 先说明学情和分组依据，再给出完整学习任务、一条共同教学支持及名单；不提供组内逐人支持建议。
- 相同任务和支持只介绍一次，其下按第一组、第二组列出名单。
- 任务及支持依据教学目标和学生真实需要，适用于当前学科；组名与任务一致，任务正文单独保留。
