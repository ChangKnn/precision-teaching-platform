# 跨学科使用示例

完整的科学学科输入与机器输出位于：

- `tests/sample-input.json`
- `tests/sample-output.json`

该示例故意包含 P、M、R 三个非空层级和 U、EA 两个空层级，用于校准以下行为：

- 分布表保留全部五级；
- 详细分析只呈现非空层级；
- M 学生按共同关系障碍形成同质组；
- 异质组只有在共同产出需要互补思维时才建议；
- P 学生可以先接受短时个体认知定向，不强制进入小组；
- 建议具体到活动与产出，但不扩写为完整教案。

## 数学情境的迁移方式

若精准教学内容为“基本不等式最值结论的完整论证”：

- M（多点结构）学生可能已经列出约束、变形、取等条件和结论，但没有说明它们之间的关系；
- 同质干预可以要求学生完成“条件—变形依据—取等条件—最值结论”关系图；
- R（关联结构）学生的进阶活动可以是改变约束条件后检验原论证是否仍成立；
- 活动仍需依据上游个体诊断中的具体障碍，不应仅看到 M 或 R 标签便直接套用。

## 语文情境的迁移方式

若精准教学内容为“依据文本证据解释人物形象”：

- U（单点结构）学生可能只使用一处言行证据；
- M（多点结构）学生可能列出多处言行但没有说明它们怎样共同表现人物特点；
- R（关联结构）学生能够把言行、情境和人物特点组织为完整解释；
- 异质合作只有在任务要求比较多种解释并形成共同证据图时才有价值，不能让 R 学生代替其他成员完成分析。

跨学科迁移时保持进阶逻辑不变，但活动内容、产出形式和教学重难点必须由 `precision_teaching_context` 与个体诊断共同决定。
