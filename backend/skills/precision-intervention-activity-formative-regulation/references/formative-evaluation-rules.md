# 形成性评价与结果处理规则

## 1. 设计目的

形成性评价不是为每个活动追加测验，而是让教师在关键位置依据学生刚刚产生的学习证据，判断目标达成情况并决定下一步怎么教。

基本结构：

`评价时机 → 学习证据 → 达成标准 → 结果处理 → 判断主体`

本 Skill 不设计干预结束后的整体成效评价。

## 2. 次数与位置

- 单节课通常设置1—2次形成性评价。
- 多课时方案一般按每课时1—2次控制，并标明所在课时。
- 优先放在支架是否撤换、阶段是否转换、分层活动是否汇合等真正需要教学决策的位置。
- 没有真实决策用途就不设置，不要求每个活动后都评价。
- 教师端“评价时机”统一写为“活动X之后”，其中X对应教师看到的顺序活动编号；并行小组完成后只对应同一个活动编号。

## 3. 评价证据优先来自活动

优先使用：

- 即时作答；
- 口头解释；
- 学习单、关系图、模型等学习作品；
- 小组讨论中的个人表达；
- 教师课堂观察；
- 在允许使用 AI 时的生机会话记录。

评价任务应短，并直接指向目标中的可观察表现。能够使用活动产出时，不另加重复测验。

## 4. 达成标准

标准应写成教师可观察的表现：学生能够独立呈现哪些要素、关系、解释、迁移或修正；尚未达到时，当前产出缺少什么关键认知结构。

不得以答案长度、关键词数量、参与热情或 SOLO 标签本身作为标准。不得在本 Skill 中重新给学生定级。

## 5. 评价结果处理

每次评价至少说明三种处理：

1. **达到目标**：进入下一任务、减弱支架、扩大迁移或与全班汇合；
2. **尚未达到**：缩小任务范围、补充关系提示、调整材料、改变组织方式或由教师/同伴提供短时支持；
3. **证据不能反映个人理解**：安排一次极短的独立表达、标注或口头说明，再作判断。

处理方式应能在课堂中立即实施，优先调整支架、任务、材料、组织方式或支持主体，不立即重讲整段内容。

## 6. 判断主体

允许的最终判断方式：

- 教师判断；
- AI 汇总后教师判断；
- 教师结合课堂观察与 AI 汇总判断。

AI 可以整理学生回答、对照标准和提示异常，但不能独立作出最终教学决定。
