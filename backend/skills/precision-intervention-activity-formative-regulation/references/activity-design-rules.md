# 学习活动设计规则

## 1. 先设计本课的真实任务

从教学内容、可用材料、已确认目标及学生实际困难出发，确定本活动要解决的学科问题。SOLO用于内部核对思考要求，不作为活动目录。不按层级分别套用“识别—列举—关联—迁移”五套通用说辞，也不把几个抽象学习动词串起来当作任务。

每项活动应使教师看清：用哪份材料提出什么问题；学生怎样独立思考、操作或讨论；交流时比较什么；形成什么产出供下一活动使用。用教师日常使用的活动名称，如案例导入、比较解法、证据交流；名称和操作必须与当前内容吻合。

“呈现材料、组织讨论、巡视指导”需要补足对象和要求。例如，已有小凡案例时，可写“请学生区分材料明确提供的事实与自己的推测，再提出一个需要解释的问题”，而非“引导学生外显认知结构”。可以给关键问句，不需要逐字课堂脚本。

## 2. 具体课堂过程与材料边界

- 教师活动写实际可执行的动作：材料呈现、任务要求、交流组织、抽样观察以及针对困难的帮助；学生活动写具体处理、比较、说明或修订的内容。
- 根据任务决定是否需要个人先写、小组比较、全班汇聚，不把三种形式固定套到每个活动中。小组合作要有共同问题或共同成果，不能只写“组内讨论”。
- 产出优先是一份实际有用的解释、解答、作品或记录；说明它如何进入交流、评价或下一活动，避免每一步新建一张学习单。
- 使用教师提供的案例、教材、题目和资料。可拟制空白提示栏或记录框架；不可编造未提供的史料、数据、案例事实、学生回答或新情境作为既有材料。缺少关键材料时列一项具体待确认事项，避免泛泛要求教师补充所有资料。
- 内容与步骤应能在分配时长、班额、设备和教师数量下完成。并行任务不依赖教师同时给多个小组讲解。

## 3. 差异化支持可调整，不固定学生上限

诊断与分层目标提供初始安排，不代表某层级学生只能完成某类活动。生成时：

- 尽量共用有教学意义的材料、问题背景或成果格式；根据真实困难在任务入口、加工深度、提示或挑战上作适量区分，不必四项全部不同。
- 组名采用当前任务名称；不以“前结构组、关联组”等标签固定学生，也不按SOLO层级逐项解释该组“适合做什么”。
- 把帮助写成教师能执行的安排：观察到什么表现，提供什么提示；学生能够独立完成后如何减少提示或继续挑战。优先一种真正有用的支持，避免把“各组怎样做”和“各组用什么支架”重复列两遍。
- 教师依据课堂表现允许学生少用提示、继续更有挑战的问题，或先补充必要基础、接受个别帮助。原定分组和近期目标不是学习上限；学生可以调整支持或参与方式，不在本Skill中重新定级或改写机器目标归属。
- 有差异化安排时，在实施说明或相关活动中简短提醒一次：“以上安排供起步参考，教师可根据课堂表现调整任务和支持，学生可继续挑战更高要求。”不在每组后重复。

### 示例：共同案例中的不同支持，而非不同层级的固定任务

以下只说明写法；仅当小凡案例、理论解释与教育支持属于输入材料和上游目标时使用，不将其套入其他学科。

共同任务可以是：阅读小凡案例，提出一个最值得解释的问题，结合学过的教育理论写出解释，并说明一项教育建议的依据。

- 教师请学生先独立写出判断；小组比较不同解释，选出一条依据较充分的建议，交流它回应了案例中的什么需要。
- 有学生难以起步时，教师请其先选一项案例表现，并提供“案例表现—相关理论—我的解释”空白提示；能够独立说明后可不再使用提示。
- 有学生能够形成解释时，鼓励其检查同伴的理由：“材料中的哪一处支持这条建议？还缺什么信息？”有余力者进一步考虑哪些新信息会使自己改变建议。
- 交流使用刚才形成的解释与建议，回到材料核对依据。各学生均可参与比较与修订；不预先规定某层级学生只能填写第一栏。

这不是要求所有学生完成完全相同的任务。上游已确认并行路线时，保留其映射与进阶重点，将差别写成具体任务和可调整的支持，不写成层级定义。

## 4. 活动组织和上下游衔接

- 阶段表示真实先后，同阶段并行单元合并为一项教师端活动，分别保留来源单元和目标引用；共同要求只写一次，不把各组编号为连续活动。
- 只在同一单元内确有先后独立任务时拆分子活动，保持目标映射、阶段和原时长总和；不擅自改变上游课堂路径。
- 组织形式使用全班集体干预、同质小组干预、异质小组干预、个体干预。“综合应用”是任务功能，“学习站”是路径或空间安排，均不直接作为组织形式。
- 标题使用“活动X：名称”，下列活动时长和教学组织形式；表内保留活动目标、活动过程、学习材料与资源、学习产出。活动过程内部为教师活动、学生活动、AI辅助。
- 目标用学生能做到的具体表现表达；SOLO、PG、ST、单元编号及映射仅保留在机器字段中。目标的认知要求仍须与上游一致，不能通过润色降低要求。
- 必要支持落实在教师或学生活动中，材料栏只列实际准备的工具。机器支架字段保留供追溯；教师正文不再重复展示一套同义支持说明。

## 5. 交付前自查

教师能否按这份说明知道怎样开始、怎样让学生做、怎样组织交流、何时帮助、收集什么、怎样接续？如果删去SOLO或内部编号后只剩“分析、讨论、提升”，说明任务还没有设计具体，需要重写。
