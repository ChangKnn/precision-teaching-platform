# 学习活动设计规则

## 1. 从进阶目标反推活动

先判断活动要促成哪一种认知变化，再选择内容、任务和支架。不得只依据活动形式或工具生成方案。

| 进阶方向 | 学生应完成的核心加工 | 适合的任务方式 | 支架重点 |
| --- | --- | --- | --- |
| P→U | 进入任务，聚焦核心信息，形成一个有效认知点 | 关键信息辨认、材料与问题对应、从范例中找出一个有效点 | 缩小信息范围、明确任务对象、给出要素清单或示例起点 |
| U→M | 从一个要素扩展到多个彼此区分的相关要素 | 补充、列举、比较不同材料或不同方面 | 分类框架、遗漏提醒、并列记录表 |
| M→R | 建立要素间的关键关系并形成整体解释 | 比较、分类、因果链、证据—推理—结论、关系图、自我解释 | 关系提示、连接词、半成品关系图；达标后撤除 |
| R→EA | 概括、迁移、分析条件和边界、修正模型 | 变式任务、反例分析、新情境迁移、条件改变、模型评价 | 开放问题、反例或新情境，不提供完整推理路径 |
| EA→更高水平 EA | 进行远迁移、多模型比较、假设生成或知识重构 | 多方案评价、边界检验、跨情境建模、提出并检验假设 | 保持开放性，支持证据搜集与反思 |

如果上游目标不是相邻 SOLO 进阶，用目标中的可观察表现确定任务，不强行套用上述活动。

## 2. 内容—任务—支架一致

每个活动必须回答四个问题：

1. 学生处理什么具体内容或材料？
2. 学生必须做什么，而不只是“学习”或“讨论”？
3. 学生需要完成怎样的思考？
4. 什么学习产出能够看见这项思考？

任务动词应具体，例如“圈出、分类、连接、解释、比较、修正、迁移”。避免“理解、掌握、提升”等无法直接观察的表述。

## 3. 只做必要的差异化

- 有共同任务时，优先共享材料、问题背景或成果格式，减少课堂切换。
- 差异化重点放在任务深度、支架强度、组织方式或学习产出之一，不必每项都不同。
- 同一活动不要堆叠多种支架。优先选择一个最能突破当前障碍的支架。
- 支架要写明提供对象、支持内容、强度和撤除条件。

支架强度：

- 高约束：明确范围、步骤框架或可选项，帮助学生进入任务；
- 中等引导：提供关系框架、提示问题或半成品工具；
- 低约束挑战：提供反例、新情境或开放要求，保留学生自主推理。

## 4. 活动合并与拆分规则

教师端活动序号表示课堂推进的先后，而不是不同小组的数量。

- 一个阶段只有一个活动单元时，通常生成一项活动。
- 同一阶段包含多个同时开展的活动单元时，合并为一项分组并行活动；在同一张活动表中逐组写明目标、学生、任务、支架和产出。
- 机器结果必须保留合并前的全部上游单元编号及其分组映射。
- 不得把同时开展的分组分别编号为连续活动。

只有同时满足以下条件才可把一个上游单元拆分为两个连续子活动：

- 单元内部确有两个需要依次完成的认知动作；
- 两个子活动仍服务同一上游目标和同一学生范围；
- 组织形式不变；
- 子活动时长之和等于原活动单元时长；
- 拆分能够降低执行难度，而不是增加展示篇幅。

不得跨阶段拆分，不得通过拆分新增目标或改变学生分组。

## 5. 课堂可实施性

- 优先使用普通教室已有的教材、学习单、投影、板书和学生作品。
- 并行活动要让教师可以巡视与抽样，不依赖教师同时进行多段讲解。
- 活动说明应让教师快速看懂“谁、做什么、用什么、产出什么”。
- 活动名称、时长和组织形式写在表格上方，格式为“活动X：名称（时长；组织形式）”。
- 活动表只保留活动目标、活动过程、学习材料与资源、学习产出四个一级项目。
- 活动目标从上游已确认目标中选择并结合本活动内容操作化，标注SOLO层级或进阶方向；全班共同活动承接共同目标，分层并行活动分别承接对应分层目标，汇聚或应用活动整合相关目标。
- 活动过程内部设置教师活动、学生活动、AI辅助三个二级栏目。教师活动写教学组织与专业判断，学生活动写学生实际完成的认知加工和操作，同伴互动归入学生活动，AI辅助只写AI具有明确增益的作用。
- 分层活动在学生活动中分别写明各组任务与支架；教师活动或AI辅助确有差异时才逐组说明。
- 学习材料与资源只列本活动实际使用的材料、工具和平台；学习产出说明可以观察或收集的学生成果。
- AI 使用的设计原则留在内部规则中，不在教师方案里显示“设计提示”。
- 教师端活动表不设置整表表头，也不使用“设计要素”“输出内容”“设计提示”等生成过程用语。“教师活动、学生活动、AI辅助”不得放在整表表头，只能位于活动过程内部。
- 活动表每行只保留实施核心，不加入理论解释、诊断长文或完整教案套话。

## 6. 组织形式选择

组织形式只允许以下四类：

| 组织形式 | 适用情形 |
| --- | --- |
| 全班集体干预 | 需要共同定向、共同示范、全班汇聚或形成共同认识 |
| 同质小组干预 | 学生的当前障碍和进阶目标相近，需要相同任务或支架 |
| 异质小组干预 | 不同思维优势能够互补，且合作本身有明确的共同建构价值 |
| 个体干预 | 需要独立作答、个别支架、个人迁移或确认个人理解 |

选择时依据活动目标、目标学生、互动需要和课堂条件，不把活动功能当作组织形式：

- “综合应用”说明任务要求学生进行整合、迁移或运用，应写入活动目标或学习活动内容；
- “学习站”说明课堂路径或空间安排，应进一步判断实际采用同质小组、异质小组还是个体干预；
- 上游路径代码若为 C/H/X/I，可作为选择参考；若为 A/S，必须重新确定四类组织形式之一。
