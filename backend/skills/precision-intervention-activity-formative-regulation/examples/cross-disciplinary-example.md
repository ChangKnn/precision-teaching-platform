# 跨学科简例：科学课“食物网证据推理”

本例展示同一时间的三个分组任务如何合并为一个教师端活动。完整机器字段见 `tests/sample-output.json`。

## 活动2：分组并行探究食物网证据（20分钟；个体干预、同质小组干预）

|  |  |  |  |
| --- | --- | --- | --- |
| **活动目标** | 基础支持组：找到一条有效食物关系（P前结构→U单点结构）。<br>关系建构组：把多项信息连成关系链并完成解释（M多点结构→R关联结构）。<br>迁移检验组：改变条件，检验并修正原有解释（R关联结构→EA拓展抽象结构）。 |  |  |
| **活动过程** | **教师活动** | **学生活动** | **AI辅助** |
|  | 说明各组任务、材料和共同产出要求；巡回查看证据使用情况，并按学生表现调整或撤除支架；组织各组交流。 | 学生先独立处理材料并留下个人判断，再完成本组任务：<br>• 基础支持组从候选关系中选出一条有效关系，使用简化图和两色标注卡。<br>• 关系建构组把数据卡排成至少两步的关系链，说明箭头含义后撤去文字提示。<br>• 迁移检验组判断条件变化后原解释是否适用，再利用反例修正解释。 | 向迁移检验组提供条件变化或反例，并追问修正理由；不提供完整关系链或结论。 |
| **学习材料与资源** | 简化食物网图、数据卡、箭头关系卡、解释修正单；具备条件时使用AI对话工具。 |  |  |
| **学习产出** | 基础支持组：一条有效关系。<br>关系建构组：完整关系链及解释。<br>迁移检验组：解释修正单。 |  |  |

## 形成性评价

| 评价时机 | 对象与目标 | 评价任务与证据 | 达成标准 | 评价结果处理 | 判断主体 |
| --- | --- | --- | --- | --- | --- |
| 活动2之后 | 三个分组及其对应进阶目标 | 查看各组自然形成的产出，并抽取个人作简短说明。 | 学生能够完成本组目标要求的有效关系、关系链解释或条件修正。 | **达到：** 携带本组产出进入全班汇聚。<br>**尚未达到：** 保留原支架，先观察对应范例再短时修正。<br>**个人证据不清：** 独立补写一个关系或修正理由。 | 教师判断 |

## 使用提醒

- 活动编号只表示课堂推进顺序；同时开展的小组任务不另编活动号。
- 教师方案不显示“设计提示”“设计要素”“输出内容”等生成过程用语。
- 单节课通常只设置1—2次形成性评价，不为每项活动都增加评价。
- AI 只有在具备明确作用时才写入“AI辅助”，且不替代学生思考或教师判断；无必要时该单元格留空。
