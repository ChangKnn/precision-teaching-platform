# 跨学科写法参照：把分层依据转为具体课堂活动

## 科学：已有食物网图和种群变化数据卡

本例只展示写法和支持调整。使用前须核对教师材料与上游目标，不补写虚构种群数据。

### 活动2：探究种群变化

活动时长：20分钟；教学组织形式：个体干预、同质小组干预

|  |  |  |  |
| --- | --- | --- | --- |
| **活动目标** | 能依据图和数据说明种群变化的可能原因，指出解释所依据的关系或条件。具体路线承接各自已确认目标，不在正文贴层级标签。 |  |  |
| **活动过程** | **教师活动** | **学生活动** | **AI辅助** |
|  | 请学生先写一个判断，交流时带着图上的连线或数据说明。发现学生找不到相关信息时，帮助缩小观察范围；能找信息但解释跳步时，请其逐个说明箭头含义；已经形成解释时，请其检查成立条件。根据现场表现减少提示或补充支持，学生可继续挑战。 | 共同使用已有图和数据，留下个人判断。食物关系辨认：标出相关生物和材料依据，连出一条关系；种群变化解释：将支持判断的信息连起来，与同伴核查每一步的理由；解释条件检验：检查原解释成立的条件，并说明何时需要修订。带着各自的图示或解释进入全班交流；这些是起步任务，教师可按实际表现调整。 | 仅在教师允许且学生已有解释时，协助检验条件；使用教师许可的反例任务，学生核查后说明是否修订。无可用AI或无实际需要时留空。 |
| **学习材料与资源** | 教师已有食物网图和种群变化数据卡；按需准备空白连线或关系提示，具备条件时使用共享设备。 |  |  |
| **学习产出** | 供全班交流的个人标注或解释，能够指出其材料依据；需要修订的地方保留修改痕迹。 |  |  |

三条路线不是能力标签；可先获得必要帮助，也可减少提示或继续更复杂的解释。保留上游目标映射，不把学生永久限制在某一路线。

## 大学教育学：已有小凡案例

不要写“各组按SOLO层级完成解释、关联、迁移”。可以写：每人先选出最值得解释的现象，区分案例事实与推测，联系已学理论提出解释与一项教育建议；小组比较建议各自回应什么需要、依据是否充分，带着仍有分歧的问题进入全班交流。

难以起步者可先使用“案例表现—相关理论—我的解释”提示；能形成解释者比较不同建议的依据；有余力者思考什么新信息会使自己改变判断。教师按当场表现调整帮助，不规定某层级学生只能完成其中一项。

## 数学与历史的迁移写法

- 数学在教师已给的题目、图形和解法上展开：先独立判断，再比较关键步骤为何成立；帮助需要支持的学生标出已知条件，鼓励已有解法的学生检验适用条件。不能只写“低层识别、高层迁移”，也不凭空添加题目条件。
- 历史在教师已给的史料和问题上展开：先提出解释，再比较哪些材料支持或不足以支持该解释；需要时提供材料分类提示，有余力者检查相反证据。不得编造史料或把初始分层当作讨论资格。
