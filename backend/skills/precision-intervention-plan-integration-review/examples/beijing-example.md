# 跨学科示例：北京人证据解释任务

本示例只说明 Skill 3 如何整合与审核，不构成固定学科内容。

## 上游摘要

- 诊断任务：围绕“没有文字记载时，如何知道北京人会制作工具、使用火和群体生活”与 AI 对话，并说明证据和理由。
- 诊断发现：部分学生只能列举考古材料，不能说明材料如何支持历史结论。
- 分层目标：P/U 学生扩展有效证据点；M 学生建立“遗存—推理—结论”关系；R 学生检验解释的适用范围。
- 路径：全班共同定向 → 同质小组并行探究 → 全班汇聚 → 个体综合应用。
- 活动：比较考古材料、形成证据关系图、汇聚解释结构、迁移到新的无文字史前情境。

教师版方案先用一个“诊断任务”区块完整复制上游任务设计，再呈现班级诊断和教学情境与条件；不把题干、材料、作答方式和任务要求拆成多行。班级诊断总述应同时说明分布差异、已有基础、共同与分层障碍和下一步教学方向。

分层进阶目标表后固定保留：

> **说明：** 表中“目标层级—面向学生”的对应，是依据当前诊断为学生确定的最近发展目标，用于安排差异化支持；并不表示学生在本节课中只能达到该层级。学生达到当前目标后，可以继续向更高层次进阶，教师应根据形成性评价动态调整目标与支持。

学习活动采用教案式活动表。活动名称、时长和组织形式位于表格上方；表格只保留活动目标、活动过程、学习材料与资源、学习产出。“教师活动、学生活动、AI辅助”仅作为活动过程内部的三个二级栏目。会话圈保留在机器结果中用于审核，不在教师方案中单列。
