# 八类审核规则

审核时只向教师呈现八类结果。以下判断点用于内部分析，不拆成更多教师端检查项。

## R1 诊断—目标一致性

核心问题：为什么这些学生需要这个目标？

- 阶段性进阶目标能追溯到真实的层级、主要表现和进阶障碍。
- 目标认知变化与诊断起点相匹配。
- 从 U 直接跳到 EA 等不合理跨级目标标记为 `× 需要修改`，除非上游给出充分且明确的任务特定依据。

## R2 目标—活动一致性

核心问题：学生实际做的事情是否足以促进目标中的认知变化？

- 活动要求的认知加工与目标一致。
- M→R 不能只继续找更多信息，必须要求建立关系和整体解释。
- R→EA 不能只是把原答案写得更长，必须涉及迁移、概括、边界、假设或评价。
- 活动表面关联主题但不产生目标所需加工时，标记为 `× 需要修改`。

## R3 路径—活动一致性

核心问题：细化活动是否忠实落实上游整体路径？

- 每个路径节点都有对应活动或明确的合并关系。
- 每个活动都能追溯到路径节点。
- 活动顺序、并行结构、分流和汇合与 Skill 1 一致。
- 使用上游 `stage_id`、`unit_id` 和拓扑结构核对，不擅自替换组织路径。

## R4 差异化合理性

核心问题：差异是否来自真实学习需要？

- 检查差异位于内容、任务要求、支架或组织形式中的哪一处。
- 三组仅被分成简单题、中等题、困难题，而认知加工没有差异时，至少标记为 `△ 建议优化`；如果因此无法促进目标，标记为 `× 需要修改`。
- 能共用同一材料或活动时，不为了“精准”机械分层。
- 避免不必要的“一人一方案”。

## R5 支架适切性

核心问题：支架是在帮助学生思考，还是替学生思考？

- 低水平学生支架不能不足，高水平学生支架不能过强。
- 支架不能直接给出目标认知加工的完整答案。
- 能够撤除时应说明渐退条件。
- 直接替代关系建构、迁移判断等核心加工的支架标记为 `× 需要修改`。

## R6 活动—形成性评价一致性

核心链条：`进阶目标 → 活动 → 学习证据 → 判断标准 → 后续调整`。

- 评价证据由活动自然产生，或只增加很低的额外负担。
- 判断标准关注目标认知结构，不只看答案是否正确。
- 调整规则能够回应达到、尚未达到或证据无法归属于个体等情形。
- 一般每课时 1—2 次；明显过多时标记为 `△ 建议优化`，影响实施时标记为 `× 需要修改`。

## R7 师生机角色合理性

核心问题：教师、同伴和 GAI 是否承担了与活动功能相匹配的角色？

- AI 必须有明确增益，不因平台存在而每个活动都使用。
- 普通材料可以更好完成时，建议不用 AI。
- 同伴参与应产生比较、解释、质疑或共同建构等认知价值。
- 教师承担任务定向、关键追问、专业判断和教学调整。
- AI 不替代学生核心思考，不替代教师最终判断。

## R8 课堂可实施性

核心问题：教师能否在真实课堂中理解并执行？

综合检查：

- 时间：顺时活动时长之和不超过总时长，并行活动只计算一次；
- 组织：不进行过于频繁的分组、移动和材料切换；
- 教师负担：不要求教师同时进行多个一对一指导；
- 资源：不使用教师未提供的设备、材料或 AI 条件；
- 人数：小组数量和规模符合班额；
- 复杂度：教师能够快速看懂并组织。

理论上精准但课堂上无法执行时，标记为 `× 需要修改`。

## 状态写法

| 状态 | 使用条件 |
| --- | --- |
| `✓ 通过` | 没有发现需要调整的问题 |
| `△ 建议优化` | 可以实施，但存在清楚、具体的优化点 |
| `× 需要修改` | 存在明显冲突或无法可靠实施 |

每个 `△` 或 `×` 必须同时给出具体问题和最小修改建议。不得只写“需要优化”。
