# 下游完整对话契约

## 目的

本 Skill 生成的完整原始对话应可直接写入 `solo-student-diagnosis-feedback` 的 `human_ai_dialogue` 字段。

## 消息格式

```json
{
  "turn_id": "turn-0001",
  "role": "assistant",
  "content": "消息原文"
}
```

要求：

- `role` 只使用 `assistant` 或 `student`；
- `turn_id` 在一个会话内唯一并按真实顺序递增；
- `content` 保存当时实际显示或输入的完整原文；
- 不删除学生的空泛、重复、错误或越界表达；
- 不把内部执行记录写入对话；
- 不用AI改写后的版本替换学生原话。

## 支持来源区分

后续诊断只把学生表达作为学生证据，并结合先前AI提供过的帮助判断其独立性。教师允许的解释、反馈或角色信息可以出现在AI消息中；不得改记为学生观点。内部记录据实标记本轮是否引入答案相关内容或评价，不把这些标记当作所有角色必须为false的限制。若发生越出教师权限的回复，保留原文供审核，不修改已经发生的对话。
