# 精准干预课堂路径推荐与构造规则

路径表示课堂在时间上如何推进、不同学生在同一时段如何组织，不等同于SOLO认知层级的排列，也不是完整活动设计。

## 一、先推荐组织模式，再构造阶段

必须依次完成两步：

1. 判断哪一种课堂组织方式最适合当前诊断、目标、内容和条件；
2. 把共同活动和分层活动排成有先后关系的阶段，以及同一阶段内同时发生的活动单元。

不得因为目标呈P→U→M→R→EA递进，就直接判断课堂活动必须依次发生。不同学生围绕不同进阶目标同时学习时，课堂组织仍属于并行。

## 二、组织模式、路径表征及教师端写法

| 符号 | 教师端名称 | 用途 |
|---|---|---|
| C | 全班共同活动（C） | 共同定向、共性问题处理、全班汇聚或总结 |
| H | 同质小组活动（H） | 相似障碍或相近目标学生的集中支持 |
| X | 异质小组活动（X） | 不同经验、证据或思维优势之间的互补建构 |
| I | 个体学习或个别支持（I） | 独立思考、个性化任务或短时个别支持 |
| S | 学习站（S） | 承担不同教学功能的活动站点 |
| A | 综合应用（A） | 在综合、开放或新情境中运用学习成果 |

教师端优先使用文字，符号只放在括号中；不要另列“符号说明”。`→`表示先后，`{…｜…}`表示同一阶段同时开展。例如：

> 全班共同定向（C）→ 分层活动同时开展〔个体学习（I）｜同质小组活动（H）〕→ 全班汇聚（C）→ 综合应用（A）

本Skill不使用E评价节点。

教师端必须区分：

- **主要组织模式**：写一个模式或两个模式的组合，如“递进推进型＋并行分层型”；
- **模式说明**：用一句话说明该模式在本课中的含义和运行方式；
- **课堂推进安排**：写共同活动、并行活动和综合应用的具体先后关系。

不要把“并行分层型：共同定向—分层并行—共同汇聚—综合应用”整体放在“主要组织模式”中，以免与课堂推进安排重复。

### 组合模式规则

组织模式可以单独使用，也可以由两个模式组合使用。组合时，两个模式必须分别解释不同的课堂属性：

- **递进推进型**描述课堂整体的时间结构，即学习活动按照共同定向、认知加工、汇聚整合、综合应用等前后阶段逐步深化；
- **主线嵌入型、并行分层型或站点轮转型**描述核心学习阶段处理学生差异的主要组织机制。

除完全并行或几乎完全个体练习的课堂外，只要存在两个以上具有前后依赖的共同阶段，就应考虑把“递进推进型”与主要差异化模式组合。组合模式最多两个，避免用多个标签代替清楚说明。

## 三、第一步：推荐主要路径

### 1. 判断共同经历

先判断是否存在所有学生都需要的共同定向、核心内容、共同产出或最终整合。存在时，路径至少保留一个共同开始或共同汇聚阶段；不要让分层目标变成彼此割裂的课程。

### 2. 判断学生差异形态

- **多数学生具有共同发展方向，差异可在共同序列中处理**：可单独采用递进推进型；
- **多数学生可沿共同主线推进，少数学生有局部且可短时补足的缺口**：倾向主线嵌入型；
- **存在两个以上目标、障碍或支持需要相对清晰的临时群体**：倾向并行分层型；
- **学生需要的不是高低层次，而是多个功能不同且可拆分的学习模块**：考虑站点轮转型；
- **差异难以形成有意义的群体，且学生能够独立持续学习**：考虑个体自驱型。

“少数学生”不能只按比例判断，还必须同时满足：人数在教师可短时支持范围内、缺口局部、能够在一个阶段内补足且不长期脱离共同主线。

### 3. 判断教学内容与任务结构

- 后一内容必须建立在前一内容之上：支持递进推进；
- 同一内容能形成不同加工深度或支持强度的等值任务：支持并行分层；
- 主体任务可以持续，个别前置缺口可短时补足：支持主线嵌入；
- 内容能拆为功能相对独立的模块，轮转不破坏前后依赖：支持站点轮转；
- 内容适合通过持续表达、反馈和修正形成个体进阶：支持个体自驱。

### 4. 用实施条件淘汰不可行方案

检查总时长、班额、可用材料、设备、空间、教师可同时管理的活动数量和学生独立学习能力。

若候选路径都能匹配诊断与内容，优先选择：

1. 并行活动数量更少；
2. 教师管理成本更低；
3. 学生共同学习机会更多；
4. 不依赖未提供的设备或资源；
5. 能在总时长内完成共同开始、差异化学习和共同汇聚。

### 5. 按固定顺序形成推荐结论

不得直接凭路径名称或单一比例作出推荐。按以下顺序比较候选路径：

| 判断顺序 | 必须回答的问题 | 决策作用 |
|---|---|---|
| 1. 学生差异 | 学生需要的是共同推进、少数短时补足、多个临时群体、功能轮转，还是高度个体化学习？ | 确定最匹配的组织形态，是主要依据 |
| 2. 内容与任务 | 学习内容是前后依赖、同内容不同深度、可局部补足、可拆成功能模块，还是适合持续个体修正？ | 检查组织形态是否符合实际学习过程 |
| 3. 课堂条件 | 时长、班额、资源、空间和教师管理能力能否支持该组织形态？ | 不满足时直接淘汰，不得仅以理论适配保留 |
| 4. 教师偏好 | 教师更重视管理简洁、共同学习时间还是差异化强度？ | 只在前3项均可行的候选之间作最终取舍 |

推荐结果先用一句“模式说明”告诉教师该模式如何组织本课，再用2—4条具体理由回答：

1. 哪一种学生差异使该路径合适；
2. 当前教学内容为什么能按这种方式组织；
3. 现有课堂条件为什么能够实施；
4. 若有备选，主要路径相对更重视什么。

不要写“更符合学情”“更有利于因材施教”等没有指出具体诊断事实和课堂条件的泛化理由。

### 6. 五种主要路径

#### 递进推进型

适合全班需要经历明显前后依赖的认知或内容阶段，差异可嵌入每个阶段。它既可以单独作为主要模式，也可以和主线嵌入型、并行分层型或站点轮转型组合，说明课堂整体具有由浅入深、由分到合的推进过程。

#### 主线嵌入型

适合多数学生沿共同任务推进、少数学生接受短时补足。教师端必须说明支路发生在哪个阶段以及学生如何继续参与主线，但不设计评价触发规则。

#### 并行分层型

适合两个以上临时需要群体围绕共同内容，在同一时段完成不同目标或加工深度，之后共同汇聚。路径名称可具体写为“共同定向—分层并行—共同汇聚—综合应用”。

#### 站点轮转型

适合多个功能模块及可配置资源。只有空间、材料、时间和教师管理能力支持时使用；不要求所有学生机械完成全部站点。

#### 个体自驱型

适合障碍高度个体化、难以聚合，且设备、学生自我管理和教师监测条件充分的课堂。不能仅因使用AI就选择。

## 四、备选路径规则

默认只输出一个主要路径。只有两个候选路径同时满足以下条件时，才输出一个备选路径：

- 都符合学生差异形态；
- 都符合内容或任务结构；
- 都能在实施条件下完成；
- 主要差别是教师管理方式、资源使用或共同学习时间，而不是一条明显不可行。

备选路径只需说明：名称、在什么情况下更适合、相对于主要路径的具体代价。不得同时列出多个备选，也不得把不可行方案包装为备选。

将两条路径判为“适配程度接近”还必须同时满足：

1. 两条路径都通过学生差异、内容任务和课堂条件三项检查；
2. 两条路径都没有违反教师的不可协商约束；
3. 每条路径各有至少一项具体优势，不能由同一组理由直接排出绝对优劣；
4. 二者的主要差别可以表述为可由教师选择的真实取舍，例如“课堂管理更简洁”与“分层支持更充分”。

若第二候选仅在理论上可用，但明显增加管理负担、依赖缺失资源或削弱必要的共同学习，不属于适配程度接近，不输出备选路径。

## 五、第二步：构造课堂阶段

### 1. 从目标形成候选活动单元

每个进阶目标对应一个候选活动单元。若目标、障碍和所需组织方式相近，可以合并；不得机械地一名学生一个活动。

### 2. 判断先后或并行

- 某活动结果是后续活动的必要基础：安排在不同阶段；
- 不同学生可围绕同一内容同时完成不同目标，彼此没有直接先后依赖：放在同一阶段的并行活动单元；
- 并行单元共享阶段编号，内部使用唯一编号，如 `ST2-I1`、`ST2-H1`、`ST2-X1`。

### 3. 形成共同汇聚

分层活动之后原则上安排共同汇聚，使不同活动成果回到共同核心目标。汇聚活动只说明整合什么内容，不写具体操作步骤。

### 4. 分配建议时长

- 每个阶段设置一次建议时长；
- 同阶段的并行活动共享该阶段时长，不把各单元时间相加；
- 各阶段时长之和必须等于 `planned_duration_minutes`；
- 预留必要的组织转换时间；
- 若无法在总时长内实施，减少并行单元、合并相近目标或更换路径，不得虚报时长。

## 六、活动命名与教师端路径表

每个活动单元都要生成活动名称。名称采用一线教师常用的简短动宾结构，直接说明活动内容及主要学习行为，例如“辨析证据与结论”“比较不同治国方案”“迁移检验判断框架”。避免使用“活动一”“分层活动”“完成任务”等空泛名称。

只输出：

| 阶段 | 活动名称 | 组织形式 | 活动内容简介 | 面向学生与目标 | 建议时长 |
|---|---|---|---|---|---:|

“活动内容简介”说明该阶段大致学习内容和加工要求，不展开具体题目、活动步骤、支架、师生话语或评价方式。

不输出进入条件、退出条件、回归规则、形成性证据或动态分流。后续评价Skill可根据目标和阶段另行设计评价位置与调节规则。
