# 精准干预课堂路径选择与安排

先根据诊断、目标、内容和课堂条件选择组织方式，再排出具体活动。路径说明学生如何学习、活动如何衔接，不是SOLO层级的时间排序，也不是完整教学脚本。

## 一、如何选择

| 主要学习需要与内容特点 | 优先考虑 |
|---|---|
| 班级有共同发展方向；后一任务需要前一活动形成的认知成果 | 递进推进型 |
| 多数学生可持续推进，少数有能短时补足的局部缺口 | 主线嵌入型 |
| 存在清晰的临时需要群体；同一内容可用不同复杂度或支架处理 | 并行分层型 |
| 需要多种学习功能；内容能拆为相对独立的模块 | 站点轮转型 |
| 障碍高度个体化，适合持续解释、对话与修订 | 个体自驱型 |

选择须同时符合共同目标、班级证据和教师条件；不能只按层级比例或是否使用AI决定。主线支路须能在短时支持后接回原任务；站点或个体学习须有相应的空间、资源、自主学习和监测条件。条件不足时选择更简单、教师能管理的方案。

默认推荐一种。确有认知进阶链和另一差异化机制共同发挥作用时，可组合“递进推进型＋另一模式”，最多两种。只有另一个方案同样可行且有明确取舍时，才给一个备选，简述更适合的条件与代价。

组织形式含义：

| 符号 | 含义与功能 |
|---|---|
| C（Collective） | 全班共同活动：共同定向、共性问题处理、知识整合与全班提升 |
| H（Homogeneous Group） | 同质小组：按相似认知水平或障碍临时分组，进行补偿与进阶；不固定能力标签 |
| X（Heterogeneous Group） | 异质小组：通过不同观点、经验或认知水平的交流、解释与协商共同建构；不机械按层级配额 |
| I（Individual） | 个体活动：独立思考、自主练习、个性化任务、AI辅导或个别支持 |
| S（Station） | 功能学习站，不限制学习方式；站内可H/X/I |

A（Application）是综合应用或真实迁移的任务功能，可由H/X/I实施。`→`为先后，`{…｜…}`为并行，`H/X`为选择H或X，`I↔GAI`为个体交互修订，不是全班顺序阶段。“个体并行型/个体适应型”按同类机制理解，正式类型仍用个体自驱型。

## 二、五种路径的基本安排

### 递进推进型

- **基本顺序**：`C → H → X → I → A(H/X/I) → C`；可精简为`C → H/X → X/I → C`。
- **中间如何组织**：从基础建立，经针对性支持、协同建构、个体内化走向综合迁移，最后共同提升。说明后一活动使用前一活动的什么成果；不能仅因学生SOLO层级不同就让全体逐级过关。
- **可以调整**：H/X/I的选择、顺序、功能合并及跨课时展开。不同起点学生均可参与高阶活动，差异在任务复杂度、支架与支持，而非将低起点学生限定在低阶内容。

### 主线嵌入型

- **基本顺序**：`C → 主任务（局部H/I支持后回归） → C`。
- **中间如何组织**：多数学生持续推进；少数接受短时靶向支持，补足认知条件后返回主任务。说明支路发生在哪段、支持什么、接回什么任务；不能让全班暂停或让少数长期离开主线。
- **可以调整**：支路对象、支持方式和时长。通常是首尾C加中间持续主任务，支路并行不另算全班顺序活动。

### 并行分层型

- **基本顺序**：`C → {H1｜H2｜H3…} → C`，共同定向、并行学习、共同汇聚。
- **中间如何组织**：临时路径共享核心目标，按当前需要采用不同复杂度、支架和加工深度。可分别侧重要素识别、关系建构或迁移，也可并行安排必要的I支持。
- **可以调整**：组数、对象、材料及支持强度；不固定三个组或低中高标签。三个整体环节中可展开连续学习动作，不能把并行组数当作全班活动数；近期分层目标不是学习上限。

### 站点轮转型

- **基本顺序**：`C → {S1｜S2｜S3…}及按需轮转 → C`。
- **中间如何组织**：S仅表示功能站，各站写清功能、对象与站内方式，如教师指导H、同伴协作X、GAI对话I。按需要安排起始站和流动；真实轮转使用不同时间槽，同一学生不能同时在多站。
- **可以调整**：站点数、经过哪些站、轮转顺序和资源配置；不要求每人机械完成全部站点，也不假设每站都有教师或设备。

### 个体自驱型

- **基本顺序**：`C → {I1↔GAI｜I2↔GAI｜…} → C`，共同定向、个体并行、汇聚提升。
- **中间如何组织**：每个I内部有独立的微型学习回路：表达、获得追问/提示/反例等支持、修订、再表达。教师巡视、识别共性问题、核对AI建议并介入复杂困难；不放任聊天，不让AI代做。
- **可以调整**：个体任务、支持方式与进度，不规定统一对话轮数。个体微循环不是全班顺序阶段；过程支持不改写上游正式SOLO诊断。

## 三、课时与活动约束

1. **先确认范围**：典型路径可跨课时，不要求一节课完成完整链。按教师明确的本次设计范围安排，不用主题预计课时或分钟数自行推断；未说明时按单课时规划。
2. **单课时一般安排一个小组活动时段，最多两个**：第二次须有不同且必要的学习功能、清楚衔接与可行转换时间。跨课时每课时分别遵循这一规则；需要更多时合并功能、适当采用I，或提出跨课时建议交教师确认。
3. **按时段计数**：多个H/X同时开展只算一次；同一连续站点模块不按站点数或轮转次数计次。A采用H/X时计入次数，采用I时不计。活动总数服从路径和学习需要，不统一凑成3—5项。
4. **首尾共同、时长真实**：完整课堂以C开始并以C结束，承担实际认知任务；片段设计说明其位置。阶段时长之和等于教师设定，包含组织转换；并行时长计一次，真实轮转的不同时间槽分别计时。

## 四、教师能读懂的路径表述

1. **先有内容主线**：围绕本课核心问题安排学习，让前段形成的认识、方法或作品用于后段；不能只有“共同定向—分层加工—共同汇聚”的组织流程。并行活动分别回应不同困难，汇聚时写清全班要比较、整合什么，不必强行使并行分支互为先决条件。
2. **名称简短而有对象**：优先“内容对象＋学习动作”，如“分析东汉衰亡原因”“探究线面垂直条件”“比较案例解释”。可用“情境导入”“课堂小结”等自然环节名，但不把所有课都写成同一套导入、分析、总结，也不使用“要素关联加工”等内部术语。不硬设字数，以教师扫读能辨认本段为准。
3. **简介交代学习轮廓**：用一两句写明已知材料或具体问题、学生主要学习动作、形成的认识或简要成果；后续活动自然点明如何接用成果。一个关键问题可作轮廓，不展开问题串、题目全文、操作步骤或精细评价。“组织讨论、引导分析、完成进阶”不能独立充当简介。
4. **精准性落在不同做法**：共享核心材料与问题时，按真实诊断选择必要的深度或支持差异；确需不同任务则保留。每个并行单元说明本组具体处理什么，不能仅换SOLO名称或机械给五级各一套。目标和产出用教师熟悉的学科表达；CG、PG、ST、学生ID仅留在机器字段，正文不写“对应PG1至PG4”。
5. **材料有边界、示例不套用**：用教师提供的材料与课程内容。可以说明需要哪类材料；原文、图形或题目条件缺失时，不编造史料引文、出处、几何条件或实验数据，不因缺材料反复写空泛提醒。将影响实施的具体缺项列入未决事项，学习任务的完整编写交下游。参考教案只借鉴命名、问题推进和方法迁移，不假定其已有诊断证据，也不照搬分组或加入AI。

例如，已提供线面垂直教学材料时，可用“探究垂直条件”：简介写“对照材料中的不同条件，比较哪些能够保证线面垂直，形成有依据的条件判断”；后续“应用判定方法”则使用刚形成的判定条件分析给定问题。是否分组、分给谁、需要什么支持仍由本班诊断和教师条件决定，不能从这个例子直接推出。

### 历史、数学写法对照

- 历史：不写“多要素关联加工”；教师已提供东汉材料时，可写“分析衰亡原因——利用前段梳理的兴衰变化和已有史料，联系相关因素说明衰亡原因，形成供全班比较的解释”。后续“交流历史解释”比较各解释的证据和理由，修订原有判断。
- 数学：不写“完成各组认知进阶”；教师已提供线面垂直材料时，可写“探究判定条件——比较给定条件能否保证线面垂直，形成有依据的条件判断”。后续“应用判定方法”使用刚形成的条件分析给定问题。
- 这些是短写法参照，不证明当前班级应采用某种分组；目标与支持仍由实际诊断决定。活动单元仅引用目标或学习群体，不附学生名单或ID。

## 五、生成后检查

- 路径与诊断、核心/进阶目标、内容依赖及教师资源一致；课堂构想中可行的要点落实到实际活动。
- 五类路径的基本顺序保留，中段组织和可调整处明确；没有机械凑数、固定能力分流或遗漏共同开始/结束。
- 用上一节检查内容主线、具体名称、简介和成果衔接；检查并行差异是否回应诊断，正文是否混入内部编号。
- 小组次数、并行/轮转安排与时长可实施；不能实施的部分说明取舍并交教师确认。
- 只到活动轮廓与组织衔接；具体任务、详细支架、话语和形成性评价由后续设计负责。
