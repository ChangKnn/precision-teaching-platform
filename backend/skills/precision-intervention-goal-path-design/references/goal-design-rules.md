# 精准干预目标设计规则

本规则根据用户提供的论文材料整理。生成共同核心目标与分层进阶目标时必须遵守，不得以其他目标分类理论替换其核心逻辑。

## 一、共同核心目标同时依据课程要求与班级诊断

共同核心目标说明本轮全班围绕精准教学主题共同发展的方向。课程要求与学生诊断共同参与目标设计，不是先固定目标、再仅根据诊断分组补救。

- **课程依据**：中小学课程标准、单元要求与教材核心内容；大学课程大纲、课程目标与本次课程内容；以及教师明确的精准教学目标和本轮教学要求。由此确定需要发展的能力、内容范围与长期方向。
- **诊断依据**：班级思维结构分布、整体与分层分析、可追溯的实际表现、主要障碍和进阶需要。由此判断哪些表现已达到、关键联系尚缺什么、本课应从何处起步，以及需要提高到何种认知加工与迁移质量。
- **实施依据**：本次课时、资源与教师构想决定目标范围和课堂内可达到的表现，不能把跨课时的完整发展要求全部塞进本课。

### 从诊断调整目标的步骤

1. 先明确课程与教师希望发展的能力和内容，形成待校准的目标方向。
2. 对照与该能力、内容有关的诊断证据，比较学生已经达到的表现与原定要求。核对参与诊断的人数和覆盖范围，不能把两人的报告当成整个班级的水平；不重新定级。
3. 判断保留、聚焦还是提升本课目标：
   - 主要联系尚未建立：围绕课程方向聚焦本课可以发展的关键关系，保留进入共同任务的支架；不能仅因起点低就永久降低课程发展要求。
   - 多数学生已经达到原定表现：提高共同目标的加工深度或迁移要求，不能重复把已达成内容作为本课终点。
   - 多数学生已表现为EA：在同一能力方向上设置EA深化的共同目标，而不止让少数学生做拓展任务。根据真实证据选择远迁移、复杂条件下的模型比较、适用边界检验、假设生成或解释重构等一种或数种有必要的深化方向。
   - 仅少数学生达到EA：依据全班主要发展需要确定共同目标，同时为这些学生设置深化目标；不把少数人的表现直接推广到全班。
4. 用具体学习表现表达校准后的目标，再依据目标任务结构确定SOLO层级，不能先指定层级再拼凑动词。课程要求、诊断事实与明确教师要求若有冲突，说明取舍并交教师确认，不能默默忽略。

诊断具有任务情境性。某次任务中的EA不代表学生在所有内容中都达到EA；应判断原有概括或迁移是否能支持本课目标。证据不足、范围不对应或报告覆盖不足时保留限制和教师核对事项，不仅凭层级比例强行提升，也不虚构学生已具备的能力。

## 二、共同核心目标的认知结构与EA深化

目标层级取决于学生要处理的内容和认知结构：识别一个相关要素、处理多个相关要素、建立完整关系，或在完整关系基础上概括、迁移、检验与重构。“解释”等行为动词本身不能决定层级。

EA已经是SOLO最高层级。**目标提升不一定是层级代码上升，也可以是EA内部迁移距离、条件复杂度、论证质量和模型修订能力的深化。** 共同核心目标仍使用`solo_level: "EA"`，层级名称可说明“拓展抽象结构（深化）”；分层进阶目标沿用既有`EA_DEEPENING`，不生成新层级或假装从EA再升一级。

例如，课程原定目标是“运用教育理论解释案例”。若班级诊断已表明学生普遍能够整合理论并作有条件的迁移，本课共同目标可调整为：

> 面对条件发生变化的新教育情境，比较不同理论解释的适用范围，利用证据检验其边界，并修订原有解释（EA，拓展抽象结构）。

上述例子只说明设计逻辑，不能在没有相应诊断证据或教学内容时直接复制。不能只把题目变难、增加术语或题量来冒充目标提升。对仍需基础支持的学生，保留其近期进阶目标与必要支架，使其有机会参与共同高阶任务，不把共同目标提高解释为所有学生必须立即同水平达成。

教师界面继续只显示核心目标及末尾括号中的SOLO层级；不增加一套诊断依据报告。结构化结果中保留原契约要求的结构说明及表现字段，供后续活动与评价设计使用，不修改既有Schema或历史方案。

## 三、分层进阶目标

| 当前状态 | 下一步认知变化 | 常见目标层级 |
|---|---|---|
| P 前结构 | 进入任务，形成至少一个有效认知点 | U 单点结构 |
| U 单点结构 | 从一个相关要素扩展到多个不同且相关的要素 | M 多点结构 |
| M 多点结构 | 建立要素之间的关键关系并形成整体理解 | R 关联结构 |
| R 关联结构 | 概括、迁移、检验、评价或重构已有关系 | EA 拓展抽象结构 |
| EA 拓展抽象结构 | 远迁移、多模型比较、边界分析、假设生成或知识重构 | EA深化 |

生成时遵守：

1. 说明学生需要处理什么内容、形成什么结构、达到什么程度；
2. 默认建议相邻Plus One；教师提出跨级或自定义目标时，结合已有诊断与支持条件判断，不一概拒绝；
3. 不以题目难度高低替代认知结构差异；
4. 以当前层级、主要障碍和目标相近为聚合依据，不只看层级代码；
5. 每名学生只能归属一个主要进阶目标；
6. 不为没有学生的层级生成目标；
7. 已达到共同目标的学生仍需获得迁移或EA深化目标。

教师调整不改变学生原始诊断。已有依据且课内可实施的要求可以直接纳入设计；依据不足或条件冲突时，只列出具体疑问供教师核对，不新增固定审批或说明表单。

## 四、教师端与机器端字段

教师端只显示：

- 目标层级及全称；
- 具体目标内容；
- 相关学生姓名；
- 可观察的达成表现。

机器端保留：

- `goal_id`；
- 目标层级代码与全称；
- 面向的当前层级；
- 学生ID、姓名和当前层级；
- 具体目标；
- 可观察表现；
- 自定义目标时的必要说明。

不要在Skill 1输出中重复复制诊断依据、主要障碍、认知变化或与共同目标的关系。编排智能体应把原始 `diagnosis_bundle` 继续传给后续Skill。

可观察表现必须能从课堂表达、作品、操作或问题解决中识别，不能使用“理解了”“掌握了”“有所提升”等不可观察表述。

## 五、教师调整

Plus One是生成建议，不是教师调整的上限。跨级或自定义目标只需表达清楚要发展的认知结构和可观察表现，并与已有诊断、任务及课堂条件相符；已有教师要求和课堂分析可作为依据，不要求另写“为什么标准目标不足”。

保持原始诊断与名单真实，保留未涉及的教师编辑；对缺乏支持或与条件冲突的部分提出针对性提醒，由教师决定如何调整。

## 六、用教师熟悉的学习表现表达目标

目标正文说明“学生围绕什么内容，能够做出怎样的解释、判断或解决”，保留课程要求和诊断确定的认知深度，不靠堆术语体现高阶。机器层级、目标ID和学生映射保持独立，不嵌入目标正文；已有SOLO展示方式不变。

例如，“建立事实—理论—影响的关联论证”可表述为“能结合案例说明几个因素如何共同影响学生，并用材料支持自己的解释”；“迁移条件辨析”可表述为“能说明这项建议用于其他学生时，需要考虑哪些不同情况”。这些仅示范写法，不能在没有相应课程内容和证据时复制目标。目标说明要达到的表现，不展开活动流程；可观察达成表现补充判断要点，不逐字重复目标全文。
