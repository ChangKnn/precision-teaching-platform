# 输入输出契约说明

## 输入命名

六个诊断与干预 Skill 统一使用 `precision_teaching_context` 表示精准教学背景，字段固定为学科、年级、教材版本与章节、精准教学主题、精准教学目标和精准教学内容。编排智能体直接传递该对象，不再执行字段改名或结构映射。

`teacher_instructional_context` 固定包含：

- `teaching_content_and_curriculum_analysis`：AI依据精准教学基本信息辅助生成，教师修改确认；
- `teaching_focus_and_difficulty_analysis`：AI结合精准教学基本信息和班级诊断辅助生成，教师修改确认；
- `planned_duration_minutes`：教师填写的教学时长；
- `teaching_environment_and_ai_support_conditions`：教师填写的教学环境、AI可用方式、关键资源和现实限制；
- `teacher_lesson_conception`：教师可选填写的课堂教学设计构想。

班级人数从班级诊断自动读取。Skill不再要求教师填写班额、资源清单、偏好、硬约束、共同经历或预选路径类型。

## 上游诊断保持

`diagnosis_bundle.class_diagnosis` 必须保持上游原始机器结果。Skill 1不得修改学生层级、ID、姓名和典型证据。

班级诊断中的 `intervention_design_basis` 是后续方案设计的决策输入，每项包含面向学生、诊断发现、需要促进的认知变化和设计条件。Skill 1据此生成目标与路径，不把它当作已经确定的课堂活动，也不得恢复已经从上游删除的详细活动建议。

Skill 1输出不重复复制诊断依据和认知变化。编排智能体必须把以下内容分别传给后续Skill：

- 原始 `precision_teaching_context`；
- 原始 `diagnosis_bundle`；
- 原始 `teacher_instructional_context`；
- Skill 1生成的目标与课堂路径。

这样，学习活动设计和评价设计直接依据原始诊断，不依赖Skill 1的二次转述。

## Skill 1输出

### 目标

- 共同核心目标；
- 目标认知结构及理由；
- 共同目标的可观察表现；
- 分层进阶目标及学生唯一映射。

### 课堂路径

- 一个或两个主要组织模式及教师可读组合名称；
- 解释该模式在本课中如何运行的简短模式说明；
- 简短推荐理由；
- 适配程度接近时的一个备选路径；
- 教师可读的课堂推进安排及括号中的论文符号；
- 顺序阶段和同阶段并行活动单元；
- 每个活动单元的活动名称；
- 活动内容简介；
- 阶段建议时长。

不包含形成性评价节点、进入/退出条件或动态分流规则。

## 下游交接

### 给学习活动细化设计Skill

- 已确认的共同核心目标；
- 分层进阶目标及学生映射；
- 路径类型、阶段、并行活动单元和建议时长；
- 教师教学条件和硬约束；
- 原始班级诊断。

### 给形成性诊断与干预评价设计Skill

- 共同目标和分层目标的可观察表现；
- 课堂阶段和活动单元；
- 学生起点层级；
- 原始班级诊断。

评价Skill自行确定评价位置、证据任务和调节规则，不由Skill 1预设E节点。

### 给方案整合与一致性检查Skill

- 目标—学生唯一映射；
- 主要路径、备选路径、阶段和时长；
- 教师确认状态和未决条件；
- 原始输入及其他Skill输出。

## 版本与确认状态

- 初次生成：`pending_teacher_confirmation`；
- 教师明确确认后由编排智能体改为 `teacher_confirmed`；
- 教师修改目标、学生归属、路径或时长后，应触发相关下游内容重新生成或检查。
