# 简短任务分析与层级边界

## 分析的作用与限度

任务分析只用于把通用 SOLO 结构落到当前任务，不是另一套层级理论，也不是教师需要填写或阅读的清单。用简短自然语言确定认知要求、关键内容及其联系、概括或迁移机会即可。

只分析能改变层级判断的内容。不要逐个拆分题面名词、同义细节或表达形式；不设要素、关系、路径数量指标；不要将任务共同前提和已经完成的推理结论当作同级信息反复计数。若确需机器追溯，在内部字段建立最少的定位对象；没有必要就不列替代路径，缺少拓展机会时不虚构抽象方向。

整体理解并不等于列全所有次要信息，也不等于选中某个指定答案。判断学生是否通过条件、比较、因果、证据、机制或其他适当关系完成核心认知要求；不同方法只要结构等价就应被接纳。

## 相邻层级的操作化

| 边界 | 本任务中要判断什么 | 不应据此升级或降级 |
|---|---|---|
| 证据不足 / P | 是否已有足够的自主表达来判断其结构 | 空白、表达受阻或记录缺失不直接判为 P |
| P / U | 是否围绕一个真正相关的方面形成有效理解 | 出现一个术语不等于理解，选错选项也不自动是 P |
| U / M | 是否独立处理了不同的相关方面 | 同义重复、堆词、抄题面不构成多个理解方面 |
| M / R | 是否解释相关方面怎样共同支持结论或方案，形成整体 | 信息多、步骤多、篇幅长或列全要素不等于整合 |
| R / EA | 是否从完整解释中提炼可推广的原理，并作有依据的迁移、推演或边界分析 | 换一种说法、多举同类例子、宽泛口号不构成拓展 |

## 教师可读表达

不要写内部引用、代号或逐项清单条件，直接说明学生对具体内容做了什么。

例如在教学设计论证任务中，关联结构可写为：
“能结合教学目标与学生当前表现，说明为什么选择或调整某项活动，并解释如何通过学习表现判断调整是否有效。”

此句只是该任务的一种表达示范，不是跨学科固定标准；不得将这些具体要求强加给别的题目。判断依据要来自学生实际看到的任务，不因教师关注更多能力就暗加条件。

## 任务观察机会

检查任务是否允许解释关系、形成整体及展示概括或迁移，是否被材料、时间、字数或题型限制。五级标准均须完整定义，包括学生自主超越原题要求时可能呈现的有依据的高阶结构；观察机会限制记录到 task_affordance.limitations，必要时给出表下简短备注，不以此设置定级上限。可以建议如何补充任务，但不能静默改题，也不能把未展示解释为学生不能达到。

## 最小追溯

每级至少指向其通用量规锚点。只有确实使用了内部任务对象时才补充其编号；所有引用必须存在。未被任务支持的高级表现无需编造关系或抽象对象来填满追溯。

内部编号只用于 task_analysis 的定位及 trace_to 等机器字段，不进入教师可见的主要认知特征、学生表现、示例、边界或限制说明。
