# 跨学科边界校准案例

这些案例只用于理解结构差异，不是通用量规，也不能覆盖 Skill 内置通用 SOLO 量规。不要复制案例措辞到无关任务。

## 案例一：历史解释任务

任务类型：依据多则材料解释一项历史变化的原因。

- 可能的 E：材料中的经济条件、制度变化、社会行动者、时间背景；
- 可能的 R：证据—主张、条件—结果、多因素相互作用；
- M/R 边界：罗列三个原因仍可能是 M；只有说明因素如何共同作用并用材料支持解释，才可能形成 R；
- R/EA 边界：补充第四个原因不是 EA；把已形成的解释框架用于比较另一时期，并检验其边界，才可能是 EA。

## 案例二：科学实验解释任务

任务类型：根据实验设计和结果解释现象，并判断结论是否成立。

- 可能的 E：自变量、因变量、控制条件、观测结果、候选机制；
- 可能的 R：变量关系、控制—排除、证据—结论、机制—现象；
- M/R 边界：分别指出变量、数据和控制组仍可能是 M；把控制条件与数据模式组织成对结论效力的判断，才可能形成 R；
- R/EA 边界：重复结论或增加术语不是 EA；提出可检验的新预测、识别模型边界并迁移到新条件，才可能是 EA。

## 案例三：文学阐释任务

任务类型：结合文本证据解释人物选择与作品主题的关系。

- 可能的 E：人物行动、情境、语言细节、冲突、主题命题；
- 可能的 R：文本证据—解释、动机—行动、局部—整体、人物—主题；
- M/R 边界：概述情节、列出性格词和主题词仍可能是 M；用文本证据建立人物选择如何推动主题表达的整体解释，才可能形成 R；
- R/EA 边界：增加感想不是 EA；比较另一文本中的结构、提出替代阐释并评价证据解释力，才可能是 EA。

## 校准提醒

同一个动词并不固定对应某一级。“解释”可能只处理一个要素，也可能形成完整关系；“评价”如果没有基于 R 的整体结构，也不能自动判为 EA。始终回到当前任务的 E、R、整体功能和内置通用量规锚点。

## precision_teaching_context 的使用校准

- 历史情境强调“依据材料形成历史解释”，但若诊断任务只要求识记年代，不能因教学目标较高而把材料—结论关系写入当前任务的 R；应报告任务与目标不匹配。
- 科学情境包含“控制变量与证据解释”，若题目确实提供实验条件、观察结果和解释要求，`precision_teaching_context` 可帮助识别这些内容在后续学习中的位置，但 R 仍必须由题面实际要求支持。
- 文学情境聚焦“文本证据与主题阐释”，`precision_teaching_context` 可帮助区分关键文本证据与装饰性细节；不能把教材章节中的所有主题都加入当前任务的 E。

原则：`precision_teaching_context` 帮助解释任务，不替任务发号施令。目标—任务不一致时，优先保留真实任务结构，并把差异写入 `task_affordance.limitations` 和 `revision_suggestions`；跨学科案例也不能改变内置量规的五层级边界。
