# 本任务的 SOLO 分析标准

| 层级 | 主要认知特征 | 学生表现 | 示例 |
|---|---|---|---|
| P 前结构 | 本任务中的理解结构 | 教师可观察到的具体表现 | 假想学生表达 |
| U 单点结构 | 本任务中的理解结构 | 教师可观察到的具体表现 | 假想学生表达 |
| M 多点结构 | 本任务中的理解结构 | 教师可观察到的具体表现 | 假想学生表达 |
| R 关联结构 | 本任务中的理解结构 | 教师可观察到的具体表现 | 假想学生表达 |
| EA 拓展抽象 | 本任务中的理解结构 | 教师可观察到的具体表现 | 假想学生表达或留空 |

填写要求：
- 用当前任务的具体内容写完整自然语言，不只照抄通用定义。
- 主要认知特征说明理解结构；学生表现说明实际如何表达、解释或论证，不互相重复。
- 教师表格不出现内部编号、路径代码、追溯标记或需要查看另一张表才懂的引用。
- 不按术语、要点或篇幅数量机械定级，不指定唯一解法或固定表达。
- 示例只供理解标准，不是标准答案清单。
- 任务无法合理观察的级别注明“当前任务难以观察”，不据此否定学生能力。

## 使用提醒（仅在必要时补充）

说明与本任务有关的观察限制或相邻层级容易混淆之处。证据不足不直接判为前结构，接纳结构等价的不同回答。

内部分析及追溯单独留在机器 JSON 中，不在教师正文附任务拆解表和编号追溯表。
