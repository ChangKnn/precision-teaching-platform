填写要求：
- 用当前任务的具体内容写完整自然语言，不只照抄通用定义。
- 主要认知特征说明理解结构；学生表现说明实际如何表达、解释或论证，不互相重复。
- 教师表格不出现内部编号、路径代码、追溯标记或需要查看另一张表才懂的引用。
- 不按术语、要点或篇幅数量机械定级，不指定唯一解法或固定表达。
- 示例只供理解标准，不是标准答案清单。
- 五级三栏均有具体内容，不以观察机会不足替代标准或留空示例；表内不标记某级难以引出。

## 使用提醒（仅在必要时补充）

仅在存在明确观察限制时，用一两句话指出具体层级及任务原因。例如：“本任务仅要求分析当前案例，未设置迁移或一般化要求，较难激发 EA 拓展抽象层级的表现。”无明确限制时不显示备注，不用通用说明替代任务判断。五级标准仍完整保留，不以观察机会限制学生定级。

内部分析及追溯单独留在机器 JSON 中，不在教师正文附任务拆解表和编号追溯表。
